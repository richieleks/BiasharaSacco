# Biashara SACCO Management System

## Overview

This is a comprehensive SACCO (Savings and Credit Cooperative Organization) management system built with modern web technologies. The application provides functionality for managing members, savings accounts, loans, and transactions in a cooperative banking environment.

## System Architecture

### Frontend Architecture
- **Framework**: React 18 with TypeScript
- **Routing**: Wouter for client-side routing
- **State Management**: TanStack Query (React Query) for server state management
- **UI Framework**: Radix UI components with shadcn/ui design system
- **Styling**: Tailwind CSS with custom CSS variables for theming
- **Build Tool**: Vite for development and production builds

### Backend Architecture
- **Runtime**: Node.js with Express.js framework
- **Language**: TypeScript with ES modules
- **Database ORM**: Drizzle ORM for type-safe database operations
- **Database**: PostgreSQL (via Neon serverless)
- **Authentication**: Replit Auth with OpenID Connect
- **Session Management**: Express sessions with PostgreSQL storage

### Project Structure
- `client/` - React frontend application
- `server/` - Express.js backend API
- `shared/` - Shared TypeScript types and database schema
- `migrations/` - Database migration files (generated by Drizzle)

## Key Components

### Authentication System
- **Provider**: Replit Auth using OpenID Connect
- **Session Storage**: PostgreSQL-backed sessions with `connect-pg-simple`
- **User Management**: Automatic user creation and profile management
- **Authorization**: Role-based access control (admin, teller, member)

### Database Schema
- **Users**: Core user profiles linked to Replit Auth
- **Members**: SACCO member profiles with additional business data
- **Savings Accounts**: Multiple account types (regular, fixed deposit, group)
- **Loans**: Loan management with approval workflows
- **Transactions**: Comprehensive transaction tracking and audit trail

### API Structure
- RESTful API endpoints for all major operations
- Standardized error handling and logging
- Type-safe request/response validation using Zod schemas
- Authentication middleware for protected routes

### UI Components
- Modern, accessible UI using Radix UI primitives
- Consistent design system with shadcn/ui components
- Responsive design optimized for desktop and mobile
- Custom SACCO-themed color palette and branding

## Data Flow

1. **Authentication Flow**:
   - User authenticates via Replit Auth
   - Session created and stored in PostgreSQL
   - User profile automatically created/updated
   - Role-based navigation and feature access

2. **Member Management**:
   - Member profiles linked to user accounts
   - Unique member numbers and ID verification
   - Status tracking (active, inactive, suspended)
   - Search and filtering capabilities

3. **Financial Operations**:
   - Savings account creation and management
   - Deposit and withdrawal processing
   - Loan application and approval workflow
   - Transaction recording and balance updates

4. **Reporting and Analytics**:
   - Dashboard metrics and KPIs
   - Transaction history and audit trails
   - Member activity reports
   - Financial summaries and analytics

## Deployment Strategy

### Development Environment
- **Runtime**: Node.js 20 with TypeScript execution via tsx
- **Database**: PostgreSQL 16 via Replit modules
- **Hot Reload**: Vite HMR for frontend, tsx watch for backend
- **Port**: Application runs on port 5000

### Production Build
- **Frontend**: Vite build outputs static files to `dist/public`
- **Backend**: ESBuild bundles server code to `dist/index.js`
- **Database**: Migrations applied via `drizzle-kit push`
- **Deployment**: Replit Autoscale deployment target

### Environment Configuration
- **DATABASE_URL**: PostgreSQL connection string
- **SESSION_SECRET**: Session encryption key
- **REPL_ID**: Replit environment identifier
- **ISSUER_URL**: OpenID Connect issuer URL
- **REPLIT_DOMAINS**: Allowed domains for authentication
